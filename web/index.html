Key Features

为什么不是又一个噪声生成器

每个模态都被同一进展度变量驱动, 量表落点与真实分布在 KS 检验下不可区分, 行为事件按文献先验注入.

跨模态耦合

同一 progression 同步驱动 sensor 退化系数 / EMA 情绪 / 量表分数 / note 模板.

BPSD 事件注入

90% 患病率 wandering / agitation 事件按 progression-conditional 概率插入, 影响当日 EMA 与心率.
