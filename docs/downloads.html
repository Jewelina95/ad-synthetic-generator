② Clone Repo + 本地生成完整数据集 (1140 个 CSV, 981 MB)

用生成器自己跑一遍, 本地输出全部 10 患者 × 4 任务 × 30 天 = 1140 个 sensor CSV.

⚠ 为什么不直接放仓库: GitHub 单仓库推荐 < 1 GB, 我们 1140 个 CSV 总共 981 MB 接近上限. 所以代码 + 9 个样本 push, 完整数据集 clone 后 1 行命令本地重生.
# Step 1: Clone repo git clone https://github.com/Jewelina95/ad-synthetic-generator cd ad-synthetic-generator # Step 2: 装依赖 pip install numpy pandas scipy # Step 3: 跑生成器 (默认 10 患者 × 30 天) python3 src/generate_synthetic.py # 自定义: 20 患者 × 90 天 python3 src/generate_synthetic.py --patients 20 --days 90 # 输出在 data/synthetic/: # by_patient/ (个体纵向视图) # P01/sensor/dayXX_TASK.csv 每个 patient 120 文件 # by_task/ (任务为中心, VBVR-style) # walking_normal/PXX_dayXX.csv 每个任务 300 文件

③ 输出数据结构

本地生成后, data/synthetic/ 目录长这样:

data/synthetic/ ├── manifest.json # 总览 (10 患者 + 4 任务 + 语音模态说明) │ ├── by_patient/ # 视图 1: 个体纵向 (患者视角) │ ├── P01/ │ │ ├── persona.json │ │ ├── progression.csv # 30 天 progression 时序 │ │ ├── ema.jsonl # 90 条 (30 天 × 3 次/天) │ │ ├── surveys.jsonl # 5 条 (周一) │ │ ├── notes.jsonl # 1 条 (Day 14 月度) │ │ ├── bpsd_events.jsonl # BPSD 事件 (0-3 个) │ │ └── sensor/ │ │ ├── day00_walking_normal.csv # 完整 30 天 × 4 任务 │ │ ├── day00_walking_dual_task.csv │ │ ├── ... │ │ └── day29_hand_fine_motor.csv │ ├── P02/ │ ├── ... │ └── P10/ │ └── by_task/ # 视图 2: 任务为中心 (VBVR-style) ├── walking_normal/ # 10 患者 × 30 天 = 300 CSV │ ├── P01_day00.csv │ ├── P01_day01.csv │ ├── ... │ └── P10_day29.csv ├── walking_dual_task/ # 300 CSV ├── balance_standing/ # 300 CSV └── hand_fine_motor/ # 240 CSV (junkai 缺该任务)

④ CSV 列格式

所有 sensor CSV 统一 13 列:

timestamp # ISO 时间戳 gsr_filtered # EDA 皮肤电导, 退化模型: × (1-0.2*progression) ppg_ir # PPG 红外原始 hr_bpm_avg # 心率, 退化: + 3*progression bpm + 减小变异 (HRV ↓) imu_ax_mps2 # IMU 加速度 X 轴 (m/s²) imu_ay_mps2 # Y 轴 imu_az_mps2 # Z 轴 svm # Signal Vector Magnitude = √(ax²+ay²+az²) jerk # SVM 一阶差分, 退化: × (1+0.7*progression) hr_valid_flag # 心率有效性 label # 任务名 patient_id # P01..P10 (新增) day # 0-29 (新增) progression # effective_progression (新增, 患者认知退化度 0-1)

⑤ 其他文件格式

# surveys.jsonl (周量表, 每周一一条) {"day": 0, "mmse_estimate": 30.0, "moca_estimate": 26.2, "phq9": 0.0} # ema.jsonl (每日 3 次自评) {"day": 0, "hour": 9, "mood": 7, "sleep_quality": 6, "anxiety": 2, "energy": 7, "bpsd_event": null} # bpsd_events.jsonl (BPSD 事件, 按 90% 患病率注入) {"day": 25, "hour": 13, "type": "agitation", "duration_min": 30, "progression_at_event": 0.8} # notes.jsonl (月度临床 note) {"day": 14, "template": "moderate", "text": "患者 73 岁男性, 认知问题加重..."} # progression.csv (30 天进展度) day,raw_progression,effective_progression 0,0.000,0.000 14,0.500,0.575 29,0.800,0.920
