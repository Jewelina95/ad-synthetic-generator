Data Sources

真实数据 · 三类来源

生成器不是从噪声起步, 而是从两类真实信号校准: (1) 4 名健康受试者真实可穿戴 baseline; (2) 5 个 OpenNeuro 公开数据集, n=112 真实 AD/MCI/老年患者用于分布对齐.

1. 真实健康 baseline

每位受试者完成 12 项任务 (静坐 / 走路 / 双任务 / 站立平衡 / 精细手部 / ...), 同步采集 PPG (心率 + HRV) / IMU (3 轴 acc + gyro) / EDA (皮肤电导).

2. OpenNeuro 公开数据集

用于校准合成患者分布的 5 个开源队列. 涵盖 AD / FTD / MCI / 老年 / PD 共 n=560+ 受试者.
