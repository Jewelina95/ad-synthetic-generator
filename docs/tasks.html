为什么任务为中心?

最终系统会让用户做不同 task — 行走 / 双任务 / 平衡 / 手部精细 — 每个 task 训练独立的 Analyzer / Agent.

这跟 Aaron 之前的 VBVR (Video-Based Vision-Reasoning) 项目结构一致: M-002 和 M-003 是各自独立的 pipeline, 每个 pipeline 拿到与该 task 完全对齐的训练数据.

因此 v2.2 的输出同时按两个轴组织:
  • by_patient/PXX/sensor/dayXX_TASK.csv — 个体纵向视图, 用于持续监护与 EMA / 量表对齐
  • by_task/TASK/PXX_dayXX.csv — 任务为中心, 用于训练任务独立的 Analyzer / Agent
